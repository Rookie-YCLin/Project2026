## 三、第一階段的重要研究發現

第一階段已觀察到以下現象：

1. JPEG 品質因子提高時，平均平方 Frobenius 擾動整體下降，但不具有嚴格單調性。
2. 第四奇異值在 Y、U、V 各通道及整體的全部100個QF中，平均絕對擾動皆為四個奇異值中最小。
3. 第一奇異值在整體85個QF中具有最大的平均絕對擾動。
4. 第一左、右奇異向量具有顯著的方向穩定性。
5. 100個QF中，有91個QF的整體平均核範數有號擾動為負。
6. 大量區塊具有近秩虧及近重根的數值特徵。
7. QF80附近出現特殊的局部擾動低谷。

這些結果是第二階段的研究動機，不是預設的第二階段結論。

尤其需要注意：未嵌入影像的第四奇異值絕對擾動較小，不代表嵌入後第四奇異值分配必然具有較低BER。七種方法共同使用奇異值總和作為量化特徵，嵌入也會改變原始頻譜結構。

## 七、共同奇異值量化模型

令A為經YUV、Haar DWT、LL分塊、DCT及洗牌後的4×4矩陣。

A = U diag(σ) Vᵀ

σ = (σ₁,σ₂,σ₃,σ₄)ᵀ

σ₁ ≥ σ₂ ≥ σ₃ ≥ σ₄ ≥ 0

定義原始奇異值總和：

S = Σσⱼ = ||A||_*

令待嵌入位元為b∈{0,1}，全域量化步長為q>0。

目標奇異值總和為：

T = kq

其中k為非負整數，且k mod 2 = b。

在滿足各分配方法非負可行性的量化中心中，選擇距離S最近的中心。

同距時選擇較大的中心；核對Huang原始論文並記錄實際使用的邊界及取整規則。

定義有號修改量：

y = T − S

y允許為正、負或零。

修改後的奇異值必須非負。

共同區塊提取公式：

b_hat = floor(S_hat/q + 1/2) mod 2

其中S_hat必須從實際待提取矩陣重新進行SVD後計算。

禁止直接使用嵌入時保存的T代替提取特徵。

## 八、七種修改量分配方法

一般模型：

x = σ + yw

其中w為非負權重向量，Σwⱼ=1。

### S1：平均分配

w = (1/4,1/4,1/4,1/4)ᵀ

如果直接平均分配後全部奇異值非負，使用：

xⱼ = σⱼ + y/4

如果產生負奇異值，解以下受限最佳化問題：

min ||x−σ||₂²

subject to Σxⱼ=T，xⱼ≥0。

解析形式：

xⱼ = max(σⱼ+τ,0)

其中τ使Σxⱼ=T。

使用單純形投影的正確演算法，不得將負數直接截斷為零後忽略總和限制。

當T=0時，x為零向量。

### S2～S5：單一奇異值分配

分別使用：

w = (1,0,0,0)ᵀ

w = (0,1,0,0)ᵀ

w = (0,0,1,0)ᵀ

w = (0,0,0,1)ᵀ

僅修改對應的原始SVD分量。

注意：所有組別提取時仍使用四奇異值總和，而非單一奇異值。

### S6：正向比例分配

w = (σ₁,σ₂,σ₃,σ₄)ᵀ/S

### S7：反向比例分配

w = (σ₄,σ₃,σ₂,σ₁)ᵀ/S

反向比例不是倒數比例，不得錯誤實作為1/σⱼ。

當S=0時，S6及S7退化為平均分配，並記錄觸發次數。

## 九、非負可行性

對S2～S7的固定權重分配：

xⱼ = σⱼ + ywⱼ ≥ 0

因此：

y_min = −min_{j:wⱼ>0}(σⱼ/wⱼ)

T_min = S + y_min

選擇滿足以下條件的最近合法量化中心：

T=kq ≥ T_min

k≥0，k mod 2=b。

若最近的無約束量化中心不可行，應改選最近的可行中心。

不得將本來指定給單一奇異值的修改量偷偷分配至其他奇異值。

不得任意降低量化目標或更改待嵌入位元。

容許浮點誤差範圍內的微小非負修正，但修正後仍須驗證總和、奇偶量化及可行性。

必須保存：

- 原始無約束量化中心。
- 最終可行量化中心。
- 原始及實際修改量。
- 非負限制是否觸發。
- 平均分配是否使用單純形投影。
- 可行中心重新選擇次數。
- 修改量正負分布。
- 奇異值排序改變標記。
- 嚴格次序反轉與數值近似相等應分別處理。

排序改變不必強制修正，因為總和提取不受排序影響。

但重建時必須維持修改量與原始uⱼ、vⱼ的對應關係，不得將x重新排序後仍使用未同步排列的U及V重建矩陣。

## 十、矩陣重建與理論失真

修改後的矩陣：

B = U diag(x) Vᵀ

固定原始U及V，則：

||B−A||_F² = ||x−σ||₂²

對未觸發重新分配的固定權重方法：

||B−A||_F² = y²||w||₂²

平均分配：

D_avg = y²/4

單一奇異值分配：

D_single = y²

正、反向比例分配：

D_prop = y²Σσⱼ²/S²

上述正反向比例失真相同的結論建立在相同原始σ、相同y及未觸發額外可行性修正的條件下。

平均分配觸發單純形投影時，應使用實際||x−σ||₂²計算，不得強行代入y²/4。

MATLAB須獨立驗證上述數學關係。

## 十三、四矩陣研究架構

## 十四、核範數及QIM判決分析

對S1～S7，定義：

S = ||A||_*

T = ||B||_*

S₀ = ||B₀||_*

S_Q = ||C(Q)||_*

其中T應符合合法量化中心。

實際嵌入中心偏差：

e₀ = S₀−T

JPEG核範數擾動：

δ_Q = S_Q−S₀

總量化中心偏移：

e_Q = S_Q−T = e₀+δ_Q

正規化中心偏移：

z_Q = e_Q/q

目標量化中心附近的充分正確判決條件為：

|e_Q| < q/2

但由於奇偶量化具有週期性，超出此範圍不代表必然發生位元錯誤。

應另外計算：

- 相對原始目標中心的判決裕度。
- 實際奇偶量化判決結果。
- 至最近判決邊界的距離。
- 量化索引偏移及其奇偶性。
- 中心偏移的有號與絕對值。
- 未攻擊及各QF的區塊位元錯誤率。
- 跨區塊平均後、K-means前的位元投票值。
- K-means後的最終512-bit BER。

對G0，使用其原始兩奇異值量化特徵與判決規則，建立相應的中心偏移及區塊判決分析。若某項總和QIM指標不適用於G0，明確標記N/A，不虛構共同量化步長。

所有診斷中使用的真實位元與目標中心只供事後評估，禁止傳入正式盲式提取器作為判決輔助。
