# 奇異值修改量分配與 JPEG 浮水印強健性

## 1. 研究目的

我在固定的血小板影像上比較七種奇異值修改量分配，並以前人郭飛的 Common/Slow 法為對照。S1～S7 共用奇異值總和量化與同一盲式提取方式。每組先將未攻擊 8-bit PNG 的完整彩色 PSNR 校準至 40±0.1 dB，同時要求未攻擊錯誤數為 0/512，再測量各組的全部 JPEG QF 1–100。本文討論同一影像上的配對結果。

## 2. 矩陣與非負可行性

令 $A=U\operatorname{diag}(\sigma)V^\mathsf{T}$。S1～S7 對 $S=\sum_j\sigma_j$ 選取最近的合法中心 $T=kq$，其中 $k\ge0$ 且 $k\bmod 2=b$。同距依 Huang 等原式的邊界規則取較大中心。從收到影像重做 SVD，再以 $\lfloor\widehat S/q+1/2\rfloor\bmod2$ 作逐塊判決。[Huang et al., 2015](https://doi.org/10.1186/s13640-015-0073-6)

固定權重時令 $y=T-S$，$x=\sigma+yw$。每個 $w_j>0$ 給出 $y\ge-\sigma_j/w_j$，取交集得到 $T_{\min}=S-\min_{w_j>0}(\sigma_j/w_j)$。中心若落在下界之外，沿同奇偶格點選最近可行中心。S1 的 $x$ 屬於 $x_j\ge0$ 且 $\sum_j x_j=T$ 的單純形。平方距離目標為嚴格凸，KKT 條件給出 $x_j=\max(\sigma_j+\tau,0)$，其中 $\tau$ 使總和等於 $T$。$T=0$ 時 $x=0$。

令 $B=U\operatorname{diag}(x)V^\mathsf{T}$。正交不變性給出 $\|B-A\|_F^2=\|x-\sigma\|_2^2$。固定權重的平方失真為 $y^2\|w\|_2^2$。四分量平均的係數為 $1/4$，單一分量為 $1$，兩種比例分配皆為 $\sum_j\sigma_j^2/S^2$。比例分配的等值結論要求同一 $\sigma$ 與同一 $y$；不同可行區及個別校準步長會改變實際的 $y$。使用單純形投影時，直接計算 $\|x-\sigma\|_2^2$。重建按原分量保留 $x_j$ 與 $u_j,v_j$ 的配對。

$B_0$ 是 PNG 還原後的矩陣，$C(Q)$ 是該 PNG 經固定 JPEG 條件後的矩陣。$C-A=(B_0-A)+(C-B_0)$，因此平方失真還有 $2\langle B_0-A,C-B_0\rangle_F$。本文分別量測 A→B、B→B₀、A→B₀、B₀→C、A→C。重根即使依序排列仍對應不唯一基底。主統計保留全部排序索引，退化區塊與嚴格次序反轉另有標記。

## 6. 核範數、判決及 QF 80

總和量化組的 PNG 中心偏差為 $e_0=S_0-T$，JPEG 核範數改變為 $\delta_Q=S_Q-S_0$，總偏移 $e_Q=e_0+\delta_Q$。目標裕度為 $q/2-|e_Q|$，其正值給出目標格點內的充分判決條件。實際判決依整數索引差的奇偶而定，偶數格的偏移仍可給出同一位元。距最近邊界的距離為 $q/2-|S_Q-k_Qq|$。G0 另外保存兩個成分各自的中心偏移與原版判決。

## 7. 驗證與解讀範圍

MATLAB 由 A、B、B₀、C 重新計算頁面 SVD、Frobenius 範數、核範數與方向角度。七組非負分配的最大 MATLAB／Python 修改值重算差為 2.27e-13。JPEG 矩陣的最大 MATLAB 尺度化 SVD 重建殘差為 1.24e-14。Python 對可辨識個別方向的跨平台最大角度差為 3.62e-06 度，其他方向最大為 90 度。同一 MATLAB 逐塊資料重新彙整的最大尺度化統計差為 4.83e-13。Python 使用各方法的盲式入口結果作正式 BER；MATLAB 從重算 SVD 的區塊判決與正式結果在 800 組中共相差 0 個區塊，逐條件數量見交叉驗證 CSV。

本文的影像條件為固定單張血小板原圖、同一 payload 與相同 Pillow 色度取樣。各 QF 重複使用同一組嵌入位置，圖表的分位數描述完整區塊分布。若要把相關性、最有利的分量或步長外推到其他影像，需要新資料及方法固定後的獨立比較。

我另外核對全部方法的 B、B₀ 與代表性 JPEG 品質因子 1、50、80、100，共 48 組。以相鄰近重根分組比較投影矩陣，最大 Frobenius 差為 2.85e-10，最大誤差與頻譜分隔尺度界的比值為 0.11。
