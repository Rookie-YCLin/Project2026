# Project2026 第三階段研究報告

## 研究問題

本文以相同血小板影像檢驗奇異向量的自然穩定性、正交限制、矩陣嵌入失真及 JPEG 後盲式提取之間的關係。對每一組方向，本文分別比較單欄旋轉 S、Givens 旋轉 G、最短正交旋轉 R 與受限正交 Procrustes P。

## 數學驗證

MATLAB 與 Python 獨立驗證 1,625 組，其中 616 組取自正式影像。P 的正規化平方失真在兩套實作間最大差為 5.01e-15。指定反例的未分支對偶上界為 22。行列式正分支的可行及對偶目標皆為 21.5，對應平方 Frobenius 失真 17。

凍結後從 P 的八組抽取 558 個實際角度目標，再由 MATLAB 獨立重算四分支。與 Python 的正規化分支跡目標最大差為 2e-10。

血小板數學案例共 616 個配對，其中 526 個具有可行 G 平面。本文另以八組凍結 P 目標，逐一比較 304,704 個區塊的 S、G、R、P 理論失真。G 只比較原目標可行的區塊。相對改善量以基準正規化平方失真同時大於 10⁻¹² 與 P 失真證書寬度 100 倍的區塊計算。這個比值門檻將分母限制在足以區分計算誤差的位置。另保存僅採絕對門檻的平均值、極小值與樣本數，以及全部逐塊失真。P 保持因子正交與奇異值，重根子空間內用重新 SVD 找到的個別方向仍受選基影響。S 的單欄操作之後會重新分解 B。

## 自然擾動與可用性

第一階段自然角度擾動最小的成分為 V1，全 QF 合併通道平均 1.7046 度。第三階段有正式組可供比較的方向共有 3 種。逐方向資料表同列第一階段自然擾動與第三階段對應正式組的最低平均 BER。

理論 B 重新 SVD 後的目標方向絕對誤差，先對已嵌入區塊平均，再對各家族八種方向平均。G 為 0.04438 rad、P 為 0.03018 rad、R 為 0.006615 rad、S 為 0.3517 rad。
正式組平均 BER 最低的 GU1 在 A→B、B→B₀、A→B₀ 的平均平方 Frobenius 失真依序為 171.877、23.7704、142.636。三階段量值可用來定位重建前後的改變。兩段平方量與總平方量還相差誤差交叉項。

## 矩陣擾動與判決

全方法中有 32 組在某些相鄰 QF 提高時出現最終 BER 上升。這些變動保留在原始曲線。整體平均 BER 以 100 個離散 QF 同權計算。

PNG 與各 QF 的區塊級方向、間距、奇異值、位元與矩陣失真分別保存在 HDF5。關係表保留 Y、U、V 與合併通道的逐條件 Pearson 相關及光譜分類。各方法 100 個 QF 的合併通道 Pearson 相關中位數介於 -0.3330 和 -0.1815。秩類別的分母、區塊 BER 與方向偏移均在同一表保留，零筆類別的統計以缺值標示。

QF 80 的正規化偏移、判決裕度與區塊 BER 可以和前表的最終位元錯誤數對照。偏移和裕度在有合法嵌入目標的區塊上計算。區塊 BER 的分母為 38,088。

Python 與 MATLAB 逐區塊判決相差 10,510 次。其中 15 次通過原本的精確重根與距邊界 128 eps 篩查，因而列入額外查核。
從保存的角度與判決索引回查，其中 15 次跨過同一個量化中點，14 次的相對奇異值間距不超過 10⁻⁶。逐筆列於 `cross_platform_flagged_blocks.csv`。

## 解讀限制

本文使用單張影像與單一浮水印種子。重複嵌入與影像區塊結構會造成觀察值相依。相關係數描述這一張影像的量測，BER 差異同時包含失真、合法中心、正交補全、逆轉換與 JPEG 的作用。探索組因 PNG 起始條件不同，解讀時需參考各組的 PNG PSNR 與錯誤數。
