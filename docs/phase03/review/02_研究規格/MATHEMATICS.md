# 第三階段數學模型與求解證書

## 角度與純矩陣失真

令 `A = U diag(σ) Vᵀ`，`r = (1,1,1,1)ᵀ/2`。左側的坐標轉換為 `c = Uᵀr`，`R = UᵀÛ`。右側對 `Aᵀ` 以相同方式計算。方向角是 `atan2(‖x − (rᵀx)r‖₂, |rᵀx|)`。用弧度運算。角度量化中心包含端點範圍內且有指定奇偶性的整數倍，距離平手選較大中心。

正交不變性給出 `‖B − A‖²_F = Σₖ σₖ² ‖R eₖ − eₖ‖₂²`。S 只變動第 j 欄，方向向量與原向量的差平方為 `4 sin²(θ/2)`。G 在 `eⱼ,eₖ` 平面轉動，兩欄差平方相等。令 R 的實際旋轉平面由 `eⱼ,w` 張成，`wⱼ=0`，則各輔助欄的差平方為 `4 wₖ² sin²(θ/2)`。S 可選的單欄方向包含 P 的第 j 欄，P 的其餘欄僅增加非負失真，因此 `D_S ≤ D_P`。G、R 的正交解若符合相同目標角度，也在 P 可行域內。

對 P 的正交 R 展開得 `D_P=2 tr(W)−2 tr(RᵀW)`，其中 `W=diag(σ₁²,…,σ₄²)`。程式可除以 `σ₁²` 計算，最後的平方 Frobenius 失真仍使用原尺度。

## 行列式與內積四分支

令 `s = det R`、`t = ±cos(φ_target)`。固定反射矩陣 `J` 的行列式為 −1，`R=JQ` 將負行列式分支等距改寫為 `Q ∈ SO(4)`，兩個投影仍為線性函數。Ramachandran、Shu 與 Wang 的 Corollary 1 對維度至少 3 的旋轉矩陣給出二維線性像的凸性。因此每個行列式分支的集合 `{(cᵀReⱼ,tr(RᵀW))}` 是緊凸集。其上邊界的值函數對投影坐標凹。對 `−1<t<1`，上邊界在 `t` 處存在有限支持斜率，得到一個乘數使拉格朗日上界等於分支最優值。這個論證分別適用於兩個固定行列式集合。端點上的有限斜率沒有保證，直接使用固定欄補全。

對固定乘數 λ，令 `M=W+λceⱼᵀ=L diag(γ)Hᵀ`。使用正交 Procrustes 的 SVD 架構，在指定行列式分支內最大化跡得到 `Σ_{i<4}γᵢ+s det(LHᵀ)γ₄`，再扣除 `λt` 給出分支上界。最小化取樣上界時保留最好的可行解與最小的對偶上界，兩者差為證書。O(4) 直接不分支時的上界可以更寬。指定反例的行列式正分支在 λ = −17 取得 21.5，而未分支對偶為 22。

## 最優面與可行補全

滿秩且需要修正行列式時，最小奇異值若有 k 重，全部損失 (2γ₄) 可以由其子空間的一個反射承擔。投影要求化為 `vᵀSv=η`。令 `η=(1−a) λ_min(S)+a λ_max(S)`，用對應正交特徵向量的 `√(1−a)` 和 `√a` 線性組合構造 v。兩端特徵值相等時，只需檢查 η 是否等於共同值。

秩虧時非零奇異值部分固定，自由零空間的條件為指定正交變換行列式與一個投影。當自由維數 ≥2 且自由向量非零，先構造目的單位方向，再以正交補全控制行列式。自由維數為 1 時只有由行列式決定的單一符號。任一自由向量為零時，該投影恆為零。

對已固定的可行第 j 欄 x，用 N 張成 x 的正交補空間。求小型矩陣 `NᵀW_{:,-j}` 的 SVD 並做行列式修正，權重跡在剩餘三欄達到該條件下的最優值。實作在可能的非唯一最優面構造 x，再投影到精確入射條件重新做三欄補全。候選即使從數值上的近重根產生，仍用原 W 計算可行目標與對偶上界，並保存可行性誤差。

## 方向可辨識性

在有符號等價的單位向量上，`d([x],[y])=acos(|xᵀy|)` 是球面測地距離對 `x∼−x` 的商度量。三角不等式直接給出 `|d([r],[x])−d([r],[y])|≤d([x],[y])`。距合法中心小於半步長時該中心唯一最近。近重根的單欄方向對數值擾動可能敏感。重複值對應整個子空間，該子空間中的個別欄方向隨 SVD 選基改變。

將第 j 個奇異值與其最近鄰碰撞，最小的奇異值平方位移為 `gⱼ²/2`。兩者移至中點可達此值，其他奇異值保持原值。Mirsky 的 Frobenius 奇異值擾動不等式給出矩陣擾動下界，沿原左右因子只改變對角奇異值即能達界。因此 Frobenius 距離為 `gⱼ/√2`。Wedin 的定理處理有適用間隔條件的奇異子空間擾動；本階段保存的原始最近間距是描述量，跨 JPEG 條件的關聯由實際區塊觀察。
