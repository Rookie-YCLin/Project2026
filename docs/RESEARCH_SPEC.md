## 1. 實驗一：未嵌入原圖之 JPEG 擾動
- 唯一影像：《工作細胞》血小板（郭飛專案原圖；實際檔名、解析度、雜湊待確認）。
- 基礎：guofei9987/blind_watermark Common/Slow；OpenCV BGR→YUV、原版奇數尺寸補邊、單層 Haar DWT、LL、完整不重疊 4×4 blocks、DCT、逐區塊固定密碼洗牌，然後 SVD。保留邊緣處理與索引。
- A_{c,i} 是 DCT 及洗牌之後、SVD 之前的實數 4×4 矩陣。c∈{Y,U,V}、i=1,…,n，m=3n。實測確認 n，不沿用舊數字。
- A=UΣV^T=Σ_j σ_j u_j v_j^T。四奇異值降序非負；U,V 正交。每塊十二個觀察項目：4 σ、4 u、4 v。
- 對原圖獨立 JPEG 編解碼 QF=1,2,…,100；Pillow、4:4:4（subsampling=0）。每個 QF 均自同一原圖壓縮，非累積。解碼後經相同前處理、同位置同洗牌取得 Ã_{c,i}(QF)。
- 主矩陣擾動：D=||Ã−A||_F²。手稿錯誤等式已撤回，因 JPEG 前後 U、V 不同，不能把它等同於奇異值平方差。
- 同時記錄 Dσ=Σ_j(σ̃_j−σ_j)²；Mirsky 不等式 Dσ≤D 可作核對，不取代主指標。D−Dσ 可記錄，但不能稱為純奇異向量擾動。
- 各 j：絕對奇異值差 |σ̃_j−σ_j|、有號差 σ̃_j−σ_j、總和有號及絕對差。
- 各 j：左/右方向夾角 θ_u=arccos(clip(|ũ_j^T u_j|,0,1)) ×180/π；θ_v 同理。每塊先求角度再平均，0–90°，排除符號不唯一性。
- 保存奇異值間距（相鄰差及每個 j 最近的其他奇異值間距），研究其與向量擾動關係。重根/近重根時方向不唯一，記錄並說明；不能以任意重排序掩蓋現象。
- 對每個 QF、通道與索引 j，保存逐區塊原始值及平均、中位數、標準差、P90；各通道平均分母 n、整體 3n。正文以平均值為主。原始資料可採 NPZ/Parquet 等無損格式，另輸出 CSV 摘要；記錄矩陣與 SVD 因子、索引、種子及版本。
- 第一階段已獲准獨立先做；是否開始本次執行依使用者後續任務。本次文件初始化不執行。

## 2. 實驗二：七種奇異值修改量分配

共同量化特徵 S=Σ_j σ_j（核範數）。Huang et al. (2015) 式(15)–(21)：μ=floor(S/q+1/2)，選最近且索引奇偶符合 bit b 的中心 T=kq，k≥0 整數、k mod 2=b。同距依原論文分支規則。提取 b̂=floor(Ŝ/q+1/2) mod 2。此處 T 是論文的目標總和 y，本文 y=T−S 是有號總修改量。q>0。
- 已確認：y 可正、負、零；所有修改後奇異值必須非負。負 y 表示總和下降。強制 y≥0 雖可保證非負（權重非負），卻放棄最近中心，故不用。
- 7 組：平均 w=(1/4,…,1/4)；單一 w=e_j 四組；正向 w=σ/S；反向 w=(σ4,σ3,σ2,σ1)/S。所有組均量化/提取四奇異值總和，而不是讀取單一 σ_j。B=U diag(σ+yw)V^T。
- 平均組遇負值：固定 T，解 min ||x−σ||₂² s.t. Σ x_j=T、x_j≥0；唯一解 x_j=max(σ_j+τ,0)，Σ x_j=T。T=0 時 x=0。若全部非負，直接 y/4。排序自然保持。
- 單一及比例分配遇負值：維持其原始分配規則，改選距 S 最近的可行同奇偶量化中心，不將量偷偷移給其他分量。非負即可；不強制保序，因總和不受重排序影響。S=0 的比例權重邊界規則待明確定義、測試，不能除以零。
- 理論固定 y 且未觸發可行性修正時：||A−B||_F²=y²||w||₂²；平均 y²/4、單一 y²、正反向比例均為 y² Σ σ_j²/S²。平均是無非負限制被觸發時的最小失真分配，正反向有相同局部失真但可能不同 JPEG 表現。固定 y 的比較以推導為主；正式 BER 比較用相同整圖 PSNR，而非要求 q 或 y 完全相同。
- 全部使用 YUV 三通道，無其他權重探索。

## 3. 實驗三：奇異向量（尚有實作細節待定）
- 四左、四右，共八個目標索引；不做左右同時嵌入。比較單一向量旋轉和保持正交的旋轉（因此每種實作可各有八組；最終組數與表格需明確列出）。
- 單位向量 û=cosθ u+sinθ z，z⊥u、||z||₂=1。隨機方向需固定種子；同一量化特徵的隨機可行方向 vs 最小失真方向尚待討論。
- 單一向量旋轉其餘列不變，B=A+σ_j(û_j−u_j)v_j^T；||B−A||_F²=4σ_j² sin²(θ/2)。Û 通常不正交，重新 SVD 的實際 u、σ 可能不同。此方法保留重建時 Σ 的數值，但不能宣稱重分解後奇異值不變；提取必須以實際 SVD 驗證，必要時設計回饋求解。
- 正交旋轉：û_j=cosθ u_j+sinθ u_k、û_k=−sinθ u_j+cosθ u_k，其他不變。Û^T Û=I，V、Σ 固定，||B−A||_F²=2(σ_j²+σ_k²)(1−cosθ)。右側同理。相同角度下選最小 σ_k 的其他方向可降低此雙向量旋轉失真，但角度 QIM 的可行性、穩健性需檢查，不保證每個平面可達目標。
- 同向伸縮 û=(1+ε)u（ε 微小）：重建等價 σ→(1+ε)σ；重 SVD 後向量仍是單位向量，不能以向量長度盲式讀取獨立資訊。可作理論對照，是否列入十頁研究方法由作者決定。若額外做比較，須明確標為奇異值等價，而非獨立向量嵌入。
- 已接受固定參考單位向量 r（建議 (1,1,1,1)^T/2），角度特徵 φ(u)=acos(|r^T u|)∈[0,90°]，角度步長 qθ，量化到可行且奇偶符合 b 的中心，提取 floor(φ/qθ+1/2) mod 2。需處理端點、符號、重根、參考方向退化與實際重分解；最終公式與補全/方向策略須先確認，不可假定任意 θ 可盲式解碼。
- 正交性不是所有候選的強制要求，但需區分重建因子與真實 SVD。不得同時修改左右兩側作為新支線。

## 4. 正式比較條件
- 唯一血小板圖，512 bits 固定隨機 payload，固定圖像/浮水印密碼、洗牌及位置；保存實際 payload、所有種子及配置。具體數值尚未指定。
- 沿用郭飛循環分配及三通道/重複區塊平均，最終原版一維 K-means。盲式提取只用收到影像與事先共享參數，不使用原圖、真實 bit、攻擊標籤來判決。
- 郭飛對照為 Common/Slow 原版，d1=36α、d2=20α 共同倍率校準（保留原公式、比例及提取器）。
- 所有正式方法通過實際 8-bit 無損 PNG 儲存再讀取之驗收：39.9≤PSNR≤40.1 dB（相對原圖），BER=0/512。未達標先排查並修正，不納入正式比較；不得使用真實位元修補提取或放寬標準。若數學模型不可行，回報作者，不可假造成功。使用者不希望把未通過未攻擊驗收的負結果列入正文。
- 各組可各自校準步長；只用未攻擊 PSNR 與無攻擊驗收，勿以正式 attacked BER 偷調參數。保存校準歷程。所有 QF 自同一該組含浮水印 PNG 獨立 Pillow JPEG 4:4:4 編解碼。
- BER=錯誤 bits/512，逐 QF 保存錯誤數、BER、PSNR（相對原始無水印影像）。另可記錄相對未攻擊水印圖的 JPEG-only PSNR，必須清楚命名不可混淆。正式圖表不僅使用平均 BER。
- 允許部分方法低於郭飛；希望至少一種有正向效果，但不得把這當作保證或選擇性刪除攻擊後真實結果。若全部較差，優先檢查程式與公平條件，再據實分析。
- 建議圖：各通道/整體矩陣擾動、奇異值與左右奇異向量分別按 j 顯示、頻譜間距關聯、不同分配及旋轉 BER/PSNR（共用 QF 橫軸、分開縱軸）。QF 不保證單調；不平滑隱藏峰值。
- 復現：固定上游 commit、輸入 hash、依賴版本（Python/OpenCV/NumPy/PyWavelets/Pillow/JPEG）、seed、配置、原始/水印/攻擊圖或可重現生成方法、逐塊資料、逐 QF CSV、SVG、測試及執行日誌。先驗證數值與矩陣約束、roundtrip、位元判決、圖表和表格一致。
