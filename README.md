# Project2026｜矩陣理論及應用課堂專題

**研究規格基準：2026-11-24；目標交付：2026-12-01。**  
專題暫定方向：JPEG 壓縮對 4×4 區塊矩陣的奇異值與奇異向量擾動分析及其在盲式數位浮水印的應用。題名尚未由作者定稿。

## 專題主線

1. 先觀察未嵌入原始血小板影像在 JPEG QF 1–100 下的矩陣、奇異值、左及右奇異向量擾動。
2. 以 Huang (2015) 的奇偶總和 QIM 為共同特徵，比較七種奇異值修改量分配方法。
3. 比較四左、四右奇異向量各自嵌入，探討單一向量旋轉與保持正交的旋轉；用固定參考方向之角度 QIM 盲式提取。
4. 在相同初始 PSNR 40±0.1 dB、初始 BER=0 的條件下，比較各方法及郭飛原版經 JPEG 後的逐 QF BER/PSNR。
5. 完成 42 頁正式報告；數學分析為核心，程式細節在倉庫保留。
